Set up your admin login

You only do this once. Your GitHub token is locked with your password and stored with the site, so afterwards you sign in with just the password, from any device. Choose a strong password of at least 12 characters, because the locked token is publicly readable.

  1. Open GitHub → New fine-grained token. Pick the longest expiration offered.
  2. Repository access: Only select repositories → saeedmuhd.github.io.
  3. Permissions → Repository → Contents: Read and write. Generate it and paste it below.

Edit without signing in: make changes, then download the file and upload it to GitHub yourself.
